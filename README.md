### 🤖 Assignment B: Sequential & Combinational Digital Logic
*   **Focus Constraints:** Boolean algebra optimization, universal logic transformations, and timing state tracking.
*   **Key Implementations:**
    *   Designed a multi-sensor industrial process safety alarm system, executing Karnaugh Map minimizing procedures down to a universal NAND-only gate framework.
    *   Constructed a 3-bit synchronous sequential D-type shift register utilizing hardware switch debouncing filters (Schmitt Trigger architectures).
    *   Engineered a 3-bit asynchronous binary ripple counter (Modulo-8 up-counter) evaluating toggle states and signal latency delays.
